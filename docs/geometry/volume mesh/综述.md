# Delaunay-based method
- 基本CDT方法能够在well-formed的空间中生成四边形化。但理论上CDT不能保证稳定生成，这就需要在空间中加入`Steiner Points`。

!!! note "CDT"
    constrained Delaunay tetrahedrization

- `tetgen`在输入表面网格无法直接生成有效四面体化时，自动加入适量的Steiner Points以保证CDT存在

# Exact arithmetic
精确算术用于处理浮点数精度的问题。CGAL中定义了`NEF polyhedra`，将一组多边形所包裹的空间表示为显式的体积。
